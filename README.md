# emfeeld

A composable, LLM-authorable explorer for analytic electrostatic and Newtonian gravitational fields, potentials, and test-particle motion in three dimensions.

## Project direction

- Python with NumPy and SciPy for physics; an optional PyVista desktop viewer.
- Reusable prescribed sources and their superpositions, rather than separately implemented apparatuses.
- New arrangements of supported sources must be model-authoring tasks, not core-code changes.
- Explicit units, potential references, singularities, boundary assumptions, and numerical checks.
- A fixed idealized Sun with independent orbiting test particles is an initial gravitational example.
- General conductor polarization, full electrodynamics, radiation, and self-consistent many-body dynamics are outside the initial scope.

Implementation candidates are developed on branches and reviewed before merging. This initial commit records the approved project direction; it is not a runnable simulator.
