## Criteria

Record source page, givens, derived quantities, illustrative choices, model/packet hashes, validation and CLI outcomes, requested units, numeric reference checks, run counts and every revision. Packets omit expectation answers. No per-problem output is computed by the runner; reference JSON is read only after execution and cannot change packets. All observed scalar/vector shapes and units must match. Event statuses must be ok with nonnull native states and two refinement records; no_event never counts as an answered crossing request. References and tolerances in references.json are fixed before execution. Failed outcomes remain failures/partial unless a documented packet-only correction passes on a separately recorded attempt. Maximum two packet-correction rounds per case, no tolerance loosening and no engine repair during this pilot.

Known limitation controls are not solved problems or additions to the solve numerator. A schema rejection for ring and a local initial_condition_error for the rest-turn request are expected guard behaviour; they remain unsupported requested tasks. Prior SC-158 stays PARTIAL.
