## Goal and boundaries

A teacher/LLM can ask two new physical questions over already verified, named observations, without writing per-question Python or reintegrating: (a) ratio of dimensionally compatible and defensible scalar measurements; (b) Euclidean separation between distinct test bodies at exactly the same saved physical time. These are *post-processing* observations of one sealed native model run, not new native integrations or independent accuracy certificates. They must not alter or overwrite old run files. Preserve rejected and unavailable requests with explicit reasons rather than reporting zero or omitting them.

Use the independent command `python -m emfeeld.derived_observations REQUEST.json --using SEALED_NATIVE_RUN --output NEW_OUTPUT_DIRECTORY`. Require a complete exact-byte integrity inventory on the native run. The request pins the exact SHA256 of the run's `run.json` file. It declares `derived_version:1`, a safe identifier `id`, `source_run_sha256` and a nonempty list of uniquely named derived observations (maximum 32). Each derived request references existing *observation IDs* in the sealed report, not array positions. Only references and type-specific keys are accepted; no arbitrary expressions or untyped formulas.

Ratio: `{"id":"ratio","type":"ratio","numerator":{"id":"field_P","part":"magnitude"},"denominator":{"id":"field_Q","part":"magnitude"}}`. Eligible scalar measurements are field/force vector magnitudes, potential differences, saved speed and saved kinetic energy. Absolute potential/absolute potential energy and total energy are excluded because changing the arbitrary reference can alter the ratio. Both operands must have the **same exact unit**, and if either is a trajectory sample both must be trajectory samples with the **same saved time**. Values must be finite; denominator cannot be zero or numerically nonfinite. Output unit is the dimensionless SI `1`; the original operand units, observation references, selected times and values are retained. A failed authored check on either input counts as unavailable even if a numeric value was returned. The observation is dimensionless, not automatically invariant under a change of frame.

Separation: `{"id":"separation","type":"separation","left_id":"body_A_pos","right_id":"body_B_pos"}`. Both must be successful `trajectory_sample` observations with `quantity:"position"`, three finite metre values and different physical `particle_index` IDs. Compare **actual reported** saved `time_s` and `sample_index` exactly; do not infer common time from request strings or nominal index alone, interpolate, compare event times, or use rendering frames as evidence. Compute robust Euclidean norm of difference, unit `m`; reject floating overflow, missing data and unavailable numerical checks. A partial or rejected native run is refused entirely: a complete sealed source run is a prerequisite, even when some individually successful measurements may exist. Using results from partial runs would require a separate explicitly reviewed contract.

Both operations use finite float64 operands only; JSON integers/values that overflow float64 fail closed. A request with a missing, failed, malformed or mismatched operand yields a local `unavailable` result with an explicit code and null value, while unrelated requests may pass. Invalid top-level schema, duplicate IDs, invalid operation grammar, run digest mismatch, run inventory mismatch, or existing output path are hard preflight errors and create no output. Seal all output bytes in an integrity inventory that excludes the inventory itself. Each output records the exact input SHA256, native-run binding, meaning, status, result provenance, and `error_bound:null`. Native accuracy remains inherited (not independently certified). Inspection verifies source output inventory, pin, source-run inventory and bound metadata, never reruns physics.

## Frozen qualification cases

- **E1**: two named electric field probes, ratio of magnitudes; unrelated potential difference allowed only when within the same qualified domain; preserved energy/trajectory identities. Independently compute ideal source fields for a separate two-probe arrangement.
- **G1**: two independent particle position observations at the same saved time, separation; separately integrate or use analytic constant-acceleration reference where qualified. A different-time selection must return unavailable without interpolation.
- **T1**: static cross-domain gravity-field magnitude ratio and invalid absolute-potential ratio. Test that no electric/gravity unit string is conflated.

Adversarial cases: zero denominator, exact-time mismatch, same particle twice, duplicate request IDs, bad unit/type, failed measurement and authored check, tampered input or native run, nonfinite/overflow values, NaNs, missing native run inventory, existing output and path alias, malformed part, malformed position shape. Preserve every first failure; tests distinguish expected rejection from observed physics failures. Additional supported operations and complex ratios require a new reviewed contract.
